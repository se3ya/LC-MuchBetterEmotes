# Much Better Emotes
### **More emotes and a sign you can draw on, rebuilt for v81.**
---

## Features

- Emotes Middle Finger, Clap, Shy, The Griddy, Twerk, Salute, Prisyadka, Sign, Thumbs Up, Wave and 6 7
- Press/choose Middle Finger or Clap emote again for double version
- Emotes config toggle
- Emote wheel on *[ V ]* or gamepad *[ Select ]*
- Direct keys for every emote, unbound by default
- Sign emote opens UI to draw on it, color wheel, hex input, eyedropper, 8 color presets, text tool, brush sizes with 3 presets, eraser, fill bucket, undo, redo and clear
  - 8 save slots for drawings, load back onto the sign, save over a slot and deleting saved drawings
  - Scroll changes the brush size, Ctrl+Z undoes, Ctrl+Y redoes, Clear needs a second press within 2 seconds
  - Last drawing is remembered between sessions and lobbies
- Compatible with **[TooManyEmotes](https://old.thunderstore.io/c/lethal-company/p/FlipMods/TooManyEmotes/)** and **[First-Person View](https://old.thunderstore.io/c/lethal-company/p/seechela/First_Person_View/)**

---

## Configuration

### **1. Emotes**

- **Middle Finger / Clap / Shy / Twerk / Salute / The Griddy / Prisyadka / Sign / Thumbs Up / Wave / 6 7** -  Toggle emotes
- **Move While Emoting** - Walk during emotes
- **Hide Held Item** - Hides held item while player emotes

### **2. Movement**

- **Griddy Speed** - Walk speed during the Griddy. REQUIRES 'The Griddy' SET TO TRUE
- **Prisyadka Speed** - Walk speed during Prisyadka. REQUIRES 'Prisyadka' SET TO TRUE

### **3. Wheel**

- **Stop Outside Slots** - Releasing outside of slots stops your emote
- **Controller Deadzone** - How far the right stick must tilt to pick a slot, 0.25 by default and 0 to 0.9, also the left stick deadzone when drawing with a gamepad

### **4. Sign**

- **Show Other Players Drawings** - If false, keeps other players signs empty for you
- **Show While Drawing** - Other players see each line you draw. They see your drawing only when you show the sign
- **Remember Drawing** - Saves your drawing between sessions and lobbies
